# 🌍 Air Quality Index (AQI) Dashboard | Power BI

## 📌 Introduction

The **Air Quality Index (AQI) Dashboard** is an interactive Power BI project designed to analyze air quality across different cities and locations in India.

The dashboard transforms raw air-quality data into meaningful visual insights, helping users understand AQI levels, identify highly polluted cities, analyze pollutant concentrations, and observe air-quality trends.

---

## 🎯 Business Problem

Air-quality datasets can contain large amounts of information across multiple cities, pollutants, dates, and AQI measurements. Looking at raw data makes it difficult to quickly identify pollution patterns and high-risk locations.

This dashboard provides an interactive way to:

* Monitor AQI levels
* Identify the most polluted cities
* Compare air quality across locations
* Analyze major pollutants
* Understand AQI trends over time
* Filter the analysis by city, date, and AQI category

---

## 🎯 Dashboard Objectives

The main objectives of this project are to:

* Analyze overall AQI performance
* Identify the **Top 10 Polluted Cities**
* Compare AQI across cities
* Analyze pollutant levels
* Understand changes in AQI over time
* Categorize air quality based on AQI levels
* Provide an interactive and easy-to-understand dashboard

---

## 📊 Dashboard Features

### 1. AQI Overview

The dashboard provides key KPI cards for quickly understanding the overall air-quality situation.

Key metrics include:

* Average AQI
* Maximum AQI
* Minimum AQI
* City-level information
* Date-based analysis

### 2. Top 10 Polluted Cities

A bar chart highlights the cities with the highest average AQI, making it easier to identify areas experiencing higher pollution levels.

### 3. AQI Trend Analysis

The line chart shows how AQI changes over time, helping identify patterns and changes in air quality.

### 4. AQI by Location

The map visual provides a geographical view of AQI across different cities.

### 5. Pollutant Analysis

The pollutant analysis page focuses on major air pollutants and allows comparison of pollutant levels across locations.

### 6. City-Wise Pollutant Analysis

Users can compare pollutant concentrations across different cities to identify locations with higher pollutant levels.

### 7. AQI Category Analysis

The dashboard categorizes air quality into different levels:

| AQI Range | Category        |
| --------: | --------------- |
|      0–50 | 🟢 Good         |
|    51–100 | 🟢 Satisfactory |
|   101–150 | 🟡 Moderate     |
|   151–200 | 🟠 Poor         |
|   201–300 | 🔴 Very Poor    |
|   301–500 | 🟣 Severe       |
